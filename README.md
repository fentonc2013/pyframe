# PyFrame

**PyFrame** is a lightweight, modular test automation framework built in Python — designed for clarity, scalability, and maintainability.  
It’s a personal project focused on applying modern QA engineering principles to build a framework that can support both API and UI test automation while remaining tool-agnostic.

---

## 🚀 Features (in progress)

- **Modular architecture** — organized by components for easy extension and reuse  
- **Test automation ready** — integrates with [Pytest](https://docs.pytest.org/) and [Playwright](https://playwright.dev/python/) for scalable API and UI testing  
- **Plain-text configuration** — YAML-based settings for test data, environments, and endpoints  
- **CI/CD friendly** — structured to plug into build pipelines with minimal setup  
- **Logging and reporting** — extensible hooks for future reporting and analytics integration
